Lantern Crossing is a Minecraft Java 26.2 Fabric client pack. Server operators
do not need to install anything.

This development baseline contains 25 selected features and six libraries.
Light Overlay, Client Tweaks, Mod Menu, Sign Tweaks, and Iris are excluded under
the compatibility and stable-only policies. See the repository's mod audit for
the evidence and limitations.

The .mrpack references pinned upstream artifacts and includes one documented
Mouse Tweaks configuration. The .sha256 file verifies the archive bytes.

Static CI checks do not replace the clean-client vanilla-server acceptance
checklist. Consult docs/verification.md for the recorded runtime test status.
